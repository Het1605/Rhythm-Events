# Event Planner Website Imagery Guardrail

When designing or updating web applications for event planners, wedding decorators, and production agencies (e.g., Rhythm Events in Ahmedabad):

1. **Pure Event Décor & Staging Only (No Characters / Human Faces)**:
   - Do NOT use portrait photos of couples, brides, dancing crowds, or individual people as primary imagery.
   - Imagery MUST highlight the physical craftsmanship of the planner:
     - Grand wedding mandap architecture and floral domes
     - Haldi stage backdrops (yellow theme, marigold curtains, brass urlis, floral swings, cushions)
     - Mehndi festive lounge décor (colorful Rajasthani umbrellas, diwan seating, floral frames)
     - Sangeet & Garba stages (LED video walls, truss lighting, dynamic beams, dance floors)
     - Reception stages (royal loveseats, floral backdrops, lawn fairy light canopies)
     - Engagement altars (ring arches, pedestal styling, floral rings)
     - Birthday party themes (balloon garlands, backdrop panels, cake pedestals)
     - Corporate setups (conference stages, LED screens, podiums, auditorium layouts)
     - Entrance tunnels, pathway lanterns, and lighting installations.

2. **Local Cultural Authenticity**:
   - For Indian / Gujarati event planners (Ahmedabad), venues and setups must reflect authentic Indian party plots, banquet halls, lawn weddings, and traditional rituals.
   - Strictly avoid Western banquet halls, generic nightclub party confetti, or unrelated medical/stock imagery.

3. **Centralized Configuration**:
   - Store all image definitions in a dedicated config file (`src/data/images.ts`) with clear category tags, descriptive alt text, and semantic labels.
